# Рабочая папка Engee

Здесь помощник читает и предлагает сохранять файлы. Вы можете выбрать другую отдельную папку Engee в настройках.

`connection-smoke.jl` — минимальная проверка соединения. После настройки доступа Engee в «Диалоге» откройте значок папки рядом со скрепкой либо отправьте /files, затем выберите файл и нажмите «Выполнить в Engee». Интерфейс покажет код для подтверждения. Ожидаемый результат вычисления: `2.0`.

Для сложной разработки используйте облачную модель: встроенная модель 0.5B предназначена для простых автономных запросов.
