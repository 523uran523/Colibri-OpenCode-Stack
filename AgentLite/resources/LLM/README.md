# Папка локальных моделей LLM

Здесь уже находится официальная компактная **Qwen2.5-0.5B-Instruct Q4_K_M**: `qwen2.5-0.5b-instruct-q4_k_m.gguf`.

Исходных GGUF внутри разрешённых папок проекта Engee не было. Модель скачана отдельно из [официального Qwen](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF), а не скопирована из другого проекта. Размер: **491 400 032 байта**. Лицензия Apache 2.0 находится в `QWEN-LICENSE.txt`, карточка издателя — в `QWEN-MODEL-CARD.md`, SHA256 — в `SHA256SUMS.txt`.

## Добавление модели

1. Скачайте совместимый файл **GGUF**.
2. Поместите его в эту папку либо откройте «Параметры → Нейросети и подключения → Локальные модели» и выберите другую папку моделей.
3. Нажмите «Обновить список» в блоке локальных моделей, выберите нужную и нажмите «Запустить», а для уже работающей — «Использовать». Диалог автоматически переключится на эту GGUF.

Для модели из нескольких GGUF частей нужны все части рядом. Поддержка зависит от архитектуры, версии llama.cpp и памяти ПК. `safetensors`, `bin`, веса Ollama и папки Transformers не запускаются просто после копирования сюда. Их нужно конвертировать в поддерживаемый GGUF или подключать через отдельный локальный сервер. Модель 0.5B очень компактная: в проверке `1+1/2*2` она ответила `3.0` вместо `2.0`. Её арифметике и коду нельзя доверять без проверки. Для работы с Engee предпочтительнее сильная облачная или более крупная локальная модель.

## Источники

| Источник | Что использовать |
| --- | --- |
| [Hugging Face: GGUF](https://huggingface.co/models?library=gguf) | Файлы GGUF; проверяйте издателя, лицензию и память, требуемую моделью. |
| [Официальный Qwen](https://huggingface.co/Qwen) | Официальные модели; для этой папки выбирайте GGUF. |
| [Ollama Library](https://ollama.com/library) | Модели для отдельного Ollama сервера; в приложении выбирайте протокол Ollama и адрес сервера. |
| [LM Studio](https://lmstudio.ai/) | Каталог и отдельный локальный сервер с OpenAI-совместимым API. |
| [llama.cpp Releases](https://github.com/ggml-org/llama.cpp/releases) | Движок для GGUF, включая нативные сборки других ОС. |

Все пользовательские шаги и ссылки находятся в [общей инструкции](../web/public/help/guide.html#local), а подключение API — в [её разделе подключений](../web/public/help/guide.html#connections). Для удалённого сервиса откройте «Параметры → Нейросети и подключения → Ваши подключения → + Добавить подключение». Дополнительная автономная справка об облачных тарифах сохранена в [FREE_CLOUD.md](FREE_CLOUD.md). Бесплатные облачные квоты ограничены и требуют собственного доступа; ключи не распространяются вместе с общим архивом.
