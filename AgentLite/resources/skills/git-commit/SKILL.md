# Git commit
1. `bash` git status. 2. git add <файлы>. 3. git diff --cached. 4. git commit -m "что сделано".
5. Ответ: хеш, файлы, +/−.
Секреты (.env, ключи) и артефакты (node_modules, *.log, dist) не коммить. Чужие изменения не трогай.
