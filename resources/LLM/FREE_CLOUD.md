# Бесплатные облачные LLM для Engee Agent

Проверено по официальной документации 8 октября 2026 года.

## Что работает после распаковки

Общий архив не содержит личных API-ключей и сеансов. Сразу доступна локальная GGUF без облачной регистрации. Основной профиль «Бесплатный API» — OpenRouter в режиме freeOnly; для генерации требуется собственный аккаунт и ключ. Без них работа облачного API не подтверждена и не гарантируется. Другие сервисы добавляются через «Параметры → Нейросети и подключения → Ваши подключения → + Добавить подключение». Полные шаги и ссылки собраны в [общей инструкции](../web/public/help/guide.html#connections).

Облачная работа требует интернета и доступности сервиса в вашей сети. Бесплатная квота ограничена; условия, набор моделей и лимиты могут меняться. Локальная модель из этой папки служит отдельным вариантом для работы на своем компьютере.

## Подключить бесплатный OpenRouter через браузер

Откройте «Параметры → Нейросети и подключения → Ваши подключения → Подключить бесплатный API → Войти в OpenRouter». На официальном сайте войдите в свой аккаунт и разрешите создание отдельного ключа «Engee Agent — бесплатные модели». Приложение само сохранит ключ в локальной конфигурации: копировать его в чат или вручную в файл не требуется. Вход работает через [официальный OAuth PKCE](https://openrouter.ai/docs/guides/overview/auth/oauth), в том числе на локальном адресе приложения.

После входа приложение отправит бесплатной модели только тест «1+1». Если она ответит «2», OpenRouter будет выбран для диалога. Проверка использует `openrouter/free` с нулевым пределом цены, без платных резервных моделей. Если стоимость указана в ответе сервиса, она также должна быть нулевой; отсутствие поля стоимости отдельно отмечается. Ошибка сохраняет текущий выбор модели и показывает причину. Уже сохранённый ключ проверяется кнопкой «Проверить бесплатный API» без создания нового ключа. Кнопка «Отменить» прекращает ожидание.

Бесплатная квота без покупки кредитов — 20 запросов в минуту и 50 в сутки. Несколько ключей не увеличивают квоту аккаунта. При исчерпании квоты приложение не переключается на платную модель. Наличие ключа и денежный лимит `$0` сами по себе не подтверждают работоспособность: её проверяет настоящий ответ API. [Режим бесплатных моделей](https://openrouter.ai/docs/guides/routing/routers/free-router), [лимиты](https://openrouter.ai/docs/api_reference/limits).

Для Groq и OpenRouter запросы Chat Completions идут по пути /chat/completions относительно указанного адреса. Gemini использует тот же совместимый протокол. Для совместимого протокола ключ передаётся сервером в заголовке Authorization: Bearer; нативный Gemini использует x-goog-api-key. Ключи не включаются в публичный ZIP; личный архив может содержать сохранённые доступы.

## Другие варианты

**Cloudflare Workers AI.** На Workers Free предоставляется 10 000 Neurons/день. Требуются собственный аккаунт, Account ID и API token. REST-адрес: https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/run/{MODEL}. Среди вариантов: @cf/qwen/qwen3-30b-a3b-fp8 и @cf/openai/gpt-oss-20b. Некоторые новые модели требуют платного тарифного плана или prepaid credits. [Начало работы](https://developers.cloudflare.com/workers-ai/get-started/rest-api/), [стоимость и бесплатная квота](https://developers.cloudflare.com/workers-ai/platform/pricing/).

**Pollinations.** Актуальный API: https://gen.pollinations.ai/v1. Для генерации нужен ключ; без авторизации открыт каталог. Pollen покупается либо получается за выполнение Quests. Это не гарантированно бесплатное подключение при первом запуске. Новые приложения используют личный серверный ключ либо OAuth/BYOP; старые raw publishable keys являются legacy. [Авторизация и API](https://github.com/pollinations/pollinations/blob/main/gen.pollinations.ai/src/docs/apidocs-recipes.md), [Pollen FAQ](https://github.com/pollinations/pollinations/blob/main/enter.pollinations.ai/POLLEN_FAQ.md).

**Cerebras.** Постоянного бесплатного тарифа больше нет. Пробный доступ: $5 credits на 30 дней после добавления подтвержденного платежного способа. [Текущие условия](https://inference-docs.cerebras.ai/support/rate-limits).

**Hugging Face Inference Providers.** В текущем тарифе Free Users ежемесячные credits отсутствуют. Это каталог моделей и платная маршрутизация API, а не готовый бесплатный API. [Стоимость](https://huggingface.co/docs/inference-providers/pricing).

**GitHub Models.** Сервис полностью закрыт 30 июля 2026 года. Старые инструкции с этим бесплатным API устарели. [Объявление GitHub](https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026/).

## Настройка собственного сервера

Откройте «Параметры → Нейросети и подключения → Ваши подключения → + Добавить подключение → API сервиса». Выберите формат API, укажите адрес, модель из реального каталога и, если требуется, собственный ключ. Собственный JSON отправляется по точному URL без добавления маршрута; имя модели для него необязательно. Для OpenAI-compatible сервера адрес обычно заканчивается на /v1; приложение добавляет путь Chat Completions. Удаленный компьютер с Ollama также можно подключить через совместимый API при наличии разрешенного доступа к нему.

У встроенной локальной модели собственный сервер запускается из архива. Внешний локальный Ollama обычно находится по адресу http://127.0.0.1:11434/v1. Перечень моделей и способ работы конкретного подключения определяются его сервером.

## Личные данные и переносимость

Для публичного архива каждый пользователь подключает свои ключи и сеансы. Личный архив предназначен для собственного переноса сохранённых доступов; храните его конфиденциально. При облачном запросе провайдер получает сообщения и материал Engee, включенный в запрос.

У Gemini Free данные могут использоваться для улучшения продуктов Google; у OpenRouter правила зависят от выбранного upstream-провайдера. Ollama заявляет, что не использует облачные prompts и responses для обучения. Уточняйте условия выбранного сервиса перед передачей закрытых материалов.

Бесплатный тариф API не означает разрешение распространять веса модели. Для локальных файлов проверяйте лицензию модели отдельно. Puter.js SDK доступен под Apache-2.0; это отдельная лицензия от AGPL основного сервера Puter. [Лицензия SDK](https://github.com/HeyPuter/puter/blob/main/src/puter-js/README.md).

Файл содержит публичные адреса и инструкции, без API-ключей, паролей и сеансов.
