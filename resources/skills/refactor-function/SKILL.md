# Навык: рефакторинг функции

## Когда использовать
Когда нужно переписать, оптимизировать или переименовать функцию.

## Алгоритм
1. `grep` — найди функцию по имени: `grep -n "function name\|name(" file` или `grep -n "def name\|name(" file`.
2. `read` с `offset` у строки-начала функции и `limit` = размер функции + 10 строк — возьми **весь** блок.
3. Подтверди: «Функция name() в file строки X–Y. Текущее содержимое: [краткое описание]».
4. `edit` — `old_string` = полный текущий код функции (с якорем на имена и структуру), `new_string` = новый код.
5. Если функция вызывается в нескольких местах — `grep -n "name(" .` — проверь, что все вызовы совместимы с новой сигнатурой.
6. Подтверди: «Функция переписана. Вызовов найдено: N. Сигнатура [старая] → [новая]».

## Правила
- **Никогда** не пиши `new_string` без точного `old_string` — используй `grep` + `read` для получения точного кода.
- Если функция длинная (> 50 строк) — `read` в 2-3 куска с `offset`.
- После рефакторинга — `grep` подтверждает, что старые имена больше не встречаются.
- Если сигнатура изменилась — обнови все вызовы в одном же проходе.
