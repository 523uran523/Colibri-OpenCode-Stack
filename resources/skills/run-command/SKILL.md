# Навык: запуск команды

## Когда использовать
Когда нужно выполнить проверку, запуск или сборку проекта (node --check, npm install, npm start, git status и т.д.).

## Алгоритм
1. Определи команду и рабочую папку.
2. Запусти через `julia_eval_code` (или терминал) — если Julia недоступна, используй PowerShell напрямую.
3. Проверь выходной код: 0 = успех, ≠0 = ошибка.
4. Прочитай stderr/stdout. Если есть сообщения об ошибках — верни их полные тексты.
5. Подтверди результат: «Команда выполнена. Выход: N. [вывод / ошибки]».

## Правила
- Не запускай команды, которые модифицируют систему без подтверждения.
- `node --check` и `git status` — безопасные, можно запускать свободно.
- `npm install`, `git push` — требуют явного запроса пользователя.
