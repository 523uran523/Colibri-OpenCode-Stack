# Навык: чтение файла по частям

## Когда использовать
Когда нужно посмотреть содержимое файла или найти в нём что-то, а файл длинный (больше 100 строк).

## Алгоритм
1. Сначала оцени размер: `read` с `limit: 20` — посмотри первые 20 строк.
2. Если файл короткий (до 100 строк) — можно прочитать целиком.
3. Если длинный — читай **кусками**: `read` с `offset` и `limit` (например, 50–80 строк за раз).
4. Ищи нужный фрагмент через `grep` (паттерн + файл), а не читая всё подряд.
5. Для поиска по всему проекту — `grep` с каталогом.

## Правила
- **Никогда не читай файл целиком, если он больше 100 строк.**
- `offset` — 0-based, `limit` — сколько строк читать.
- Если ищешь конкретную строку — `grep` в 100 раз быстрее полного чтения.
- После `read` с `offset`/`limit` — укажи в ответе, какой фрагмент показал.
