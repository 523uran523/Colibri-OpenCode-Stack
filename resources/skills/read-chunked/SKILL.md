# Чтение кусками
1. `read` limit 20 — оценка. 2. ≤100 строк — целиком. 3. >100 — offset/limit по 50–80.
4. Ищи через `grep`, не читай всё. 5. Укажи показанный фрагмент.
6. Прочитал ровно столько, сколько просили (например 5 строк) — СТОП. Больше не вызывай read, пока пользователь не попросит продолжить.
