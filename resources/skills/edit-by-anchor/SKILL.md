# Навык: редактирование по якорю

## Когда использовать
Когда нужно вставить, заменить или удалить фрагмент кода в существующем файле, и ты знаешь точный маркер (строка, комментарий, идентификатор), который уникален в файле.

## Алгоритм
1. Вызови `grep` на якорь в целевом файле. Убедись, что найден ровно **1** совпадение.
2. Вызови `read_file` с `offset` около строки-якоря и `limit` 30–50 строк — только для того, чтобы скопировать точный контекст и форматирование.
3. Вызови `write_file` (или `edit`), передавая `old_string` = точный текст вокруг якоря и `new_string` = новое содержимое.
4. **Не читай файл целиком.** `grep` + `read_file(offset/limit)` + `write_file` — полный цикл.

## Правила
- Якорь должен быть **уникальной строкой** в файле (комментарий, константа, метод).
- Если `grep` нашёл 0 совпадений — якорь отсутствует, верни ошибку.
- Если `grep` нашёл >1 совпадения — якорь не уникален, уточни или возьми больший фрагмент.
- После `write_file` подтверди: «вставлено N строк в file на строке M».
