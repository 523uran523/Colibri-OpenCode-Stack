# Правка по якорю

Для правки НИКОГДА не вызывай read и не читай файл целиком.

Алгоритм:
1. `grep` с якорем (например `<!-- CONTACT -->`) — нужно ровно 1 совпадение.
2. `edit`: old_string = точный фрагмент с якорем из grep, new_string = замена.

0 совпадений — якоря нет; >1 — уточни якорь через grep с большим контекстом.
Ответ: файл, строка N — изменено.
