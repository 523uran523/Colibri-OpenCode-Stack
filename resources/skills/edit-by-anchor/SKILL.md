# Правка по якорю

1. `grep` якорь в файле — нужно ровно 1 совпадение.
2. `read` offset≈строка якоря, limit 20–40 — скопируй точный фрагмент.
3. `edit`: old_string = точный фрагмент, new_string = замена.
4. Файл целиком не читай.

0 совпадений — якоря нет; >1 — уточни якорь.
Ответ: «<файл>, строка N — изменено».
