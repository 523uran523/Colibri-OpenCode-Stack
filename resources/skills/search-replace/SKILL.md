# Навык: поиск и замена

## Когда использовать
Когда нужно заменить одно значение на другое в файле или файлах.

## Алгоритм
### Точечная замена (один файл, одно вхождение)
1. `grep` — найди точную строку в файле. Убедись, что совпадений ровно 1.
2. `read` с `offset` около найденной строки — возьми точный контекст (10–15 строк).
3. `edit` — `old_string` = точный текст с якорем, `new_string` = новый текст.
4. Подтверди: «Заменено N строк в file».

### Массовая замена (несколько вхождений или несколько файлов)
1. `grep -r "pattern" .` — посмотри, где все вхождения.
2. Для одного файла с множественными вхождениями — `edit` с `replaceAll: true`.
3. Для нескольких файлов — `bash`: `sed -i 's/old/new/g' file1 file2 ...` (Linux/macOS) или `powershell -Command "(Get-Content file) -replace 'old','new' | Set-Content file"` (Windows).
4. `grep` повторно — убедись, что старое значение не осталось.

## Правила
- **Всегда** `grep` **до** `edit` — чтобы знать точное вхождение.
- Если `grep` нашёл 0 совпадений — нечего менять, верни ошибку.
- Если `replaceAll` — убедись, что замена безопасна для всех вхождений.
- После замены — `grep` подтверждает, что новое значение на месте.
