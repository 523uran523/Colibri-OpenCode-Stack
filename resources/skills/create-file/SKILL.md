# Навык: создание файла

## Когда использовать
Когда нужно создать новый файл (HTML, CSS, JS, JSON и т.д.) в рабочей папке.

## Алгоритм
1. Вызови `list_files` для текущей папки.
2. Если файл с таким именем **уже существует** — не перезаписывай. Верни ошибку: «Файл существует. Используй edit-by-anchor для правки или другое имя».
3. Если файла нет — вызови `write_file` с полным содержимым.
4. Подтверди: «Создан file (N байт)».

## Правила
- Только создавай, не изменяй.
- Для правки существующих файлов — используй навык `edit-by-anchor`.
- Путь к файлу — относительный от рабочей папки.
