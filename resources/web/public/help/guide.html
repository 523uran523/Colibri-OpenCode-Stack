Шаг 1

Первый запуск

Распакуйте приложение версии 1.2.0, запустите сервер и выберите способ работы. Пакет предназначен для Windows 10/11 x64; для встроенного терминала нужна Windows 10 версии 1809 или новее.

  1. Распакуйте весь ZIP в обычную папку с правом записи, например C:\EngeeAgent. Не запускайте приложение прямо из архива.
  2. Дважды нажмите EngeeAgent.exe. Откроется браузер. Обычный адрес - http://127.0.0.1:3081/. Если порт занят, запускатель использует свободный порт 3082-3090 и откроет нужный адрес.
  3. Откройте «Параметры → Файлы проекта → Рабочая папка» и выберите рабочую папку Engee. Для чистого старта можно оставить workspace внутри приложения.
  4. Встроенная локальная модель доступна без регистрации. Выберите модель в «Диалоге» или используйте сохранённое подключение. Для другого API, локального сервера или программы откройте «Параметры → Нейросети и подключения → Ваши подключения → + Добавить подключение».
  5. Для вычислений откройте ⚙ рядом с i у отправки. В меню «Код в чате» по умолчанию выбрана Engee; локальная Julia доступна после отдельной установки. Введите /eval 1+1 и проверьте код и среду в подтверждении. Для бесплатной онлайн-модели используйте официальный вход OpenRouter в «Параметры → Нейросети и подключения → Ваши подключения».
  6. Для завершения работы нажмите кнопку питания ⏻ в правом верхнем углу (подсказка «Остановить приложение»). Сначала появится «Сохранение…»: приложение сохраняет локальные данные и только после успеха выключает сервер. При ошибке выберите «Повторить» или «Отмена». Закрытие вкладки браузера само по себе не останавливает сервер.

Что уже входит в ZIP

Node.js, CPU-движок llama.cpp с необходимыми локальными DLL, небольшая GGUF-модель Qwen, веб-интерфейс и навыки Engee. Отдельные Node.js, Python, Ollama, среда разработки и компилятор для встроенного запуска не нужны. На Windows используется системный .NET Framework; интерфейс открывается в современном браузере. Для маленькой модели рекомендуется не менее 4 ГБ оперативной памяти; скорость зависит от процессора.

Интернет нужен для Engee и облачных моделей. Встроенный локальный чат работает без интернета. Локальная нейросеть и среда Engee - разные компоненты: модель может готовить код на этом ПК, а запуск кода в Engee требует подключения к вашей среде.

Шаг 2

Ориентироваться в интерфейсе

Верхняя навигация содержит «Диалог», «Терминал» и «Параметры». Общая шапка остаётся доступной во всех разделах. Внизу «Диалога», в строке у поля сообщения рядом со скрепкой и папкой, расположена компактная кнопка с именем текущей модели. Она открывает выбор сервиса и модели.

Три точки состояния и общее обновление

В общей шапке показаны три индикатора: приложение, выбранная нейросеть и Engee. Подробное состояние находится во всплывающей подсказке точки. Нажмите общий ↻ с подсказкой «Обновить все подключения»: он обновит состояние приложения, доступность и готовность выбранной нейросети, её каталог моделей и фактическое состояние Engee. Обновление доступно из «Диалога», «Терминала» и «Параметров»; оно не отправляет задачу модели и не повторяет вычисление.

В «Параметрах» четыре вертикальные категории: «Нейросети и подключения», «Engee», «Файлы проекта» и «Компоненты». Нажмите заголовок, чтобы раскрыть или свернуть категорию. Внутри нейросетей находятся «Текущее подключение», «Ваши подключения», «Локальные модели» и «Другие сервисы»; внутри Engee — «Аккаунт», «Среда выполнения» и «Токены и конфигурация»; внутри файлов проекта — «Рабочая папка» и «Навыки». Категории и подразделы сначала свёрнуты; отдельной навигации вкладками внутри параметров нет.

Значок папки рядом со скрепкой в «Диалоге» открывает окно файлов проекта. В нём можно просматривать файлы, редактировать, создавать, сохранять, запускать их в Engee и добавлять содержимое в диалог. /files открывает это же окно. Рабочая папка и навыки настраиваются в «Параметры → Файлы проекта».

Работа с проектом включена постоянно. Помощник получает доступ к инструментам проекта, но не читает автоматически все файлы. Для понятной задачи выбирайте нужные файлы, описывайте результат и проверяйте предложенные действия.

Отправка сообщения и подтверждение действий

«Отправить» и Enter сразу отправляют задачу выбранной модели. Значок i рядом с отправкой открывает два раздела: «Контекст» для просмотра получателя и подготовленных данных и «Команды» для выбора команды. Просмотр ничего не отправляет; выбор команды только вставляет её в поле сообщения. Предложенные помощником изменения файлов, сохранение навыков и выполнение кода требуют подтверждения точного действия. Автосохранение перед выходом через ⏻ описано ниже.

Значок ? в общей шапке открывает эту единую инструкцию. Кнопка питания ⏻ сначала сохраняет локальные данные, затем завершает приложение. Ссылки «Инструкция» у компонентов ведут к нужному месту на этой же странице.

⚙ рядом с i и кнопкой «Отправить» выбирает, где выполняется код в чате: Engee или локальная Julia. Это отдельный выбор от провайдера нейросети. По умолчанию используется Engee; подсказка шестерёнки показывает текущую среду. Само переключение код не запускает.

Сохранить данные и завершить работу

Нажмите ⏻. В окне «Сохранение…» дождитесь записи изменённого файла проекта, готовых к сохранению параметров, локальной истории и восстанавливаемых черновиков. Незавершённый мастер подключения, новый файл или навык сохраняются как черновики: приложение не создаёт из неполных данных готовое подключение, файл или навык.

Если сохранение не удалось

Сервер не закрывается, пока данные не сохранены. «Повторить» снова пробует сохранение; «Отмена» возвращает к работе. Если запись уже идёт, отмена дождётся её завершения и отменит только выключение приложения. При ошибке введённые данные остаются доступными; проверьте выбранную папку и возможность записи. Не завершайте процесс вручную, если нужно сохранить правки.

Шаг 3

Выбрать и переключить модель

Внизу «Диалога» нажмите кнопку с именем текущей модели рядом со скрепкой и папкой. В открывшемся окне выберите сервис, затем его модель. Для обновления подключений и каталога используйте общий ↻ в шапке с подсказкой «Обновить все подключения».

  1. Нажмите кнопку с текущим именем модели у поля сообщения. В открывшемся выборе доступны группы «Локальные модели», «Claude» и «Бесплатный API». Для отдельного API, своего сервера или программы сначала создайте подключение в «Параметры → Нейросети и подключения → Ваши подключения».
  2. Нажмите общий ↻ в шапке или введите /models, чтобы получить актуальные модели выбранного источника. У Ollama выберите установленную модель из выпадающего списка; у API используйте реальный идентификатор из каталога.
  3. Если у сервиса нет каталога, введите точный идентификатор из его документации в мастере подключения. Сохранённый профиль меняйте через «Изменить»; после проверки нажмите «Использовать».
  4. Для встроенной GGUF выберите найденный файл из настроенной папки LLM. При первом сообщении запускается локальный движок. Для Claude Code используется установленный и авторизованный агент; копирование GGUF не настраивает Claude.
  5. Проверьте источник и модель у полученного ответа. Для точного вычисления используйте /eval и явно выберите нужную среду выполнения кода; итоговую проверку проекта Engee выполняйте в Engee.

Модели разных источников не взаимозаменяемы

Файл GGUF в resources/LLM, установленная модель Ollama, модель локального сервера LM Studio и идентификатор облачного API — разные записи. Обновление каталога обнаруживает модели, но не скачивает и не устанавливает их.

Шаг 4

Добавить и использовать подключение

Откройте «Параметры → Нейросети и подключения → Ваши подключения», нажмите «+ Добавить подключение» и выберите «API сервиса», «Локальная модель» или «Программа».

Выбор, открываемый кнопкой модели у поля сообщения, разделён на три группы: «Локальные модели» — Ollama, встроенный GGUF и LM Studio; «Claude» — установленный и авторизованный Claude Code; «Бесплатный API» — OpenRouter. Другие сервисы добавляйте через мастер. Сохранённые подключения доступны с действиями «Использовать», «Изменить», «Проверить» и «Удалить».

Подраздел «Текущее подключение» показывает активный провайдер, модель и параметры API; здесь же доступен каталог Ollama. Сохранённые записи, мастер и подключение бесплатного OpenRouter находятся в «Ваши подключения». Для изменения записи нажмите «Изменить» и используйте мастер. Общая кнопка сохранения параметров сохраняет выбор активного подключения; она не заменяет редактирование профиля.

  1. Для API выберите сервис или универсальное подключение. Укажите предоставленный сервисом адрес, формат API и собственный ключ, если он требуется. Нажмите поиск моделей и выберите реальный идентификатор из каталога; при отсутствии каталога введите точное имя из документации сервиса.
  2. Для локальной модели выберите её источник. GGUF запускается встроенным движком из папки LLM; Ollama и LM Studio используют модели, загруженные в соответствующее приложение, и адрес его сервера. Найдите модели и проверьте выбранную модель.
  3. Для программы укажите установленный инструмент и его параметры. «Открыть в терминале» запускается только вашим нажатием; автоматического входа или запуска программы при выборе записи нет. Для Claude Code и OpenCode выполните собственный вход через терминал.
  4. Сохраните подключение, нажмите «Проверить», затем «Использовать». Изменение или удаление записи относится к настройкам Engee Agent; установленная программа и файлы модели остаются на этом компьютере.

Какой формат API выбрать

ФорматКогда использовать
Chat CompletionsOpenAI-совместимый API: базовый адрес обычно заканчивается на /v1; приложение использует /chat/completions.
ResponsesСервис с API /responses. Например, профиль OpenAI использует API-ключ и модель, доступную этому ключу; вход в ChatGPT или установленный Codex сам по себе не настраивает этот профиль.
AnthropicНативный Messages API: базовый адрес https://api.anthropic.com/v1, запрос /messages. При необходимости задайте заголовок рабочего пространства, указанный в кабинете Anthropic.
GeminiНативный generateContent API: базовый адрес https://generativelanguage.googleapis.com/v1beta, точное имя модели из каталога. Ключ отправляется в заголовке x-goog-api-key.
Свой JSONУкажите полный URL запроса, JSON-шаблон и путь текста в ответе. Приложение отправляет POST ровно по этому адресу, без добавления /chat/completions. Имя модели необязательно, если её выбирает сам сервис.

В своём JSON доступны переменные {{messages}}, {{tools}}, {{model}}, {{prompt}} и {{apiKey}}. Если переменная занимает целое строковое значение, массивы и объекты сохраняют структуру. Внутри текста они подставляются как текст JSON. Путь ответа поддерживает поля через точку и числовые индексы, например result.answers[0].text. Если сервис возвращает инструменты в своей схеме, укажите путь массива вызовов и пути имени, аргументов и идентификатора. Скрипты и JavaScript в шаблонах не выполняются.

Используйте HTTPS для удалённого API или HTTP локального компьютера. Ключ задавайте отдельным полем или шаблоном заголовка {{apiKey}}, а не в URL и не в сообщении. Сохранённый ключ отмечен «Сохранён» и не загружается в браузер; «Заменить» позволяет ввести новый. «Показать/Скрыть» относится только к вручную введённому значению.

Бесплатный API требует свой доступ

Для OpenRouter используйте «Подключить бесплатный API» и официальный вход в браузере либо введите собственный ключ. Приложение проверяет доступ на публичном примере; действуют лимиты и доступность аккаунта. Это не анонимная работа без регистрации. Groq, Gemini, DeepSeek, Qwen/DashScope, Kimi и OpenAI настраиваются отдельно; бесплатная квота или пробные кредиты не означают бессрочный бесплатный API. Оплата и лимиты проверяются в кабинете сервиса.

После запуска или выбора GGUF диалог автоматически переключается на эту локальную модель. Для Ollama обновляйте список установленных моделей и выбирайте идентификатор сервера; имя GGUF не заменяет имя модели Ollama. Сохранение существующей записи Ollama не требует повторного скачивания модели.

У сообщения видно время HH:mm, источник ответа и модель либо среду выполнения — Engee или локальную Julia. Подпись «Ответ за … с» показывает фактическую длительность полученного ответа. Ответ нейросети и результат исполнения кода различаются по источнику: расчёты проверяйте через /eval, а проект Engee — выполнением в Engee.

Программа и API — разные способы работы

Подключение типа «Программа» с Claude Code, OpenCode или Codex CLI запускает отдельную программу в терминале только по вашему нажатию. Это не меняет исполняемый файл встроенного Claude Code в веб-диалоге и не настраивает автоматически OpenAI API. Установите программу и выполните её собственный вход на этом компьютере; для API добавьте отдельное подключение с собственным ключом.

Шаг 5

Подключить бесплатный онлайн API

OpenRouter предоставляет бесплатные модели через API. Для подключения нужен ваш аккаунт OpenRouter; приложение получает отдельный ключ после входа в официальном окне браузера.

  1. Откройте «Параметры → Нейросети и подключения → Ваши подключения». В карточке «Бесплатный API · OpenRouter» нажмите «Подключить бесплатный API», затем «Войти в OpenRouter ↗».
  2. В официальном окне OpenRouter войдите в свой аккаунт и разрешите отдельный ключ для Engee Agent. Вручную копировать его не требуется: после возврата в приложение ключ сохраняется локально.
  3. Дождитесь проверки: приложение отправляет только публичный пример 1+1 в openrouter/free, без файлов проекта. Успешный ответ 2 подтверждает работу текущего доступа и выбранной бесплатной модели; результат и сообщённая стоимость показываются в карточке.
  4. Если ключ уже сохранён, нажмите «Проверить бесплатный API», чтобы повторить проверку без нового входа. Ввести свой ключ вручную также можно в настройках подключения.
  5. Для прекращения ожидания нажмите «Отменить» либо Stop. Если показана ошибка, отмена или истёкшее ожидание, исправьте причину и начните подключение заново. Ожидание входа ограничено 10 минутами, проверка ответа — 120 секундами.
  6. После успешной проверки используйте OpenRouter из группы «Бесплатный API» в «Диалоге». Перед отправкой своих файлов при необходимости проверьте подготовленный контекст значком i.

Что означает бесплатный режим

Подключение работает в режиме freeOnly: openrouter/free либо фактически доступная модель с суффиксом :free. Платные модели и платные запасные варианты не используются. Без покупки кредитов официальный лимит составляет 20 запросов в минуту и 50 в сутки; дополнительные ключи не увеличивают квоту аккаунта. Доступность моделей и оставшаяся квота могут измениться.

Если сервис сообщил стоимость 0, карточка показывает нулевую стоимость проверочного запроса. Если поле стоимости отсутствует, приложение честно сообщает, что сервис её не указал: отсутствие значения не считается доказательством нулевого списания. Стоимость выбранного бесплатного маршрута описана OpenRouter; ограничение или ошибка аккаунта могут помешать запросу даже при выборе бесплатной модели.

Ключ OpenRouter нужен для онлайн нейросети и отличается от токена доступа Engee. Не вставляйте ключ в диалог, навык или файл проекта. Сохранённый ключ не показывается в браузере и не включается в публичный ZIP. Вход через OpenRouter не переносит сюда учётные данные Engee.

  1. В «Диалоге» нажмите значок папки рядом со скрепкой (подсказка «Открыть файлы проекта») либо отправьте /files. Откроется окно «Файлы проекта» для выбранной рабочей папки.

В подтверждении проверьте имя, размер, SHA256 и папку назначения /user/EngeeAgent. После разрешения файл передаётся в вашу Engee; при совпадении имени Engee добавляет суффикс. Проверьте итоговое имя в списке файлов Engee.

Шаг 7

Создать, изменить, сохранить и запустить файл

Весь обычный сценарий выполняется в интерфейсе: выберите проект, откройте редактор, сохраните текст и запустите его в Engee.

  1. Подключите рабочую папку в «Параметры → Файлы проекта → Рабочая папка». В «Диалоге» откройте значок папки рядом со скрепкой. Выберите текстовый файл и нажмите «Редактировать» либо нажмите «+ Новый файл» и укажите путь внутри проекта.
  2. В редакторе либо в поле «Содержимое» нового файла измените код. Для первой проверки выберите имя example.jl и введите println(1 + 1/2*2).
  3. Для нового файла нажмите «Сохранить в проект», для редактируемого - «Сохранить». В подтверждении проверьте путь и точное содержимое; только после разрешения выполняется запись.
  4. Подключите Engee в «Параметры → Engee» и дождитесь готовности среды. Вернитесь к сохранённому .jl или .ngscript и нажмите «Выполнить в Engee».
  5. Проверьте код в подтверждении запуска. После разрешения дождитесь реального результата Engee. Для приведённого выражения ожидается 2.0.
  6. Если модель прислала блок кода в диалоге, нажмите рядом с ним «Сохранить в проект», выберите имя файла и подтвердите запись. Затем откройте файл и нажмите «Выполнить в Engee». Оценивайте реальный вывод.

Перед выполнением

Сначала сохраните изменения: выполняется сохранённый файл. Сохранение и запуск имеют отдельные подтверждения. Ctrl+S вызывает сохранение. Для обычного текста Julia используйте .jl. Нативный .ngscript - JSON-блокнот Engee; сохраняйте его структуру и метаданные ячеек, не переименовывайте простой .jl в .ngscript.

При редактировании нативного .ngscript поле source каждой ячейки кода должно содержать одну многострочную строку. Такой файл выполняется средствами Engee как блокнот. Бинарные модели редактируйте в самой Engee, а не в текстовом редакторе.

Несохранённые изменения файла

Предупреждение «Сохранить изменения файла?» появляется перед выбором другого файла или папки в браузере, сменой рабочей папки, созданием или записью другого файла при изменённом редакторе. «Сохранить» записывает правки и продолжает действие только после успеха. «Не сохранять» отбрасывает правки и продолжает действие. «Отмена» оставляет изменённый текст. При ошибке записи правки остаются доступными. Закрытие окна файлов, переход в другую вкладку или диалог сохраняет редактор и черновик без этого предупреждения; само закрытие окна не записывает файл проекта.

При выходе через ⏻ изменения файла сохраняются автоматически до остановки приложения. Не закрывайте окно «Сохранение…» и дождитесь успешного завершения. Незавершённый новый файл остаётся восстанавливаемым черновиком, если данных для его создания ещё недостаточно.

Шаг 11

Подключить среду Engee

Нейросеть готовит задачу, а вычисление выполняет ваша запущенная среда Engee.

  1. Откройте «Параметры → Engee». Разверните «Аккаунт» для данных аккаунта, «Среда выполнения» для адреса и управления запущенной средой, «Токены и конфигурация» для привязки и ручной настройки.
  2. В «Среда выполнения» введите свой PAT/токен Engee либо используйте сохранённый локально. Сохранённый токен обозначен маской из восьми точек и отметкой «Сохранён». Для смены нажмите «Заменить» и введите новый токен; «Показать/Скрыть» относится только к новому введённому значению.
  3. Адрес среды можно оставить пустым для определения через аккаунт. При ручном вводе укажите базовый адрес работающей среды без external/command/eval.
  4. В «Аккаунт» при необходимости откройте «Логин и пароль». Сохранённый логин уже отображается; сохранённый пароль обозначен маской и отметкой «Сохранён». Для смены нажмите «Заменить», введите новый пароль и сохраните параметры. «Показать/Скрыть» показывает лишь новый введённый пароль. Пустое неизменённое поле сохраняет прежний пароль.
  5. Нажмите «Проверить Engee», затем «Обновить версии». Выберите версию из доступных вашей лицензии. Значение «Таймаут простоя, минут», его минимум и максимум загружаются из параметров лицензии; выберите допустимое значение. Если лицензия запрещает изменение таймаута, поле отключено: запуск использует значение аккаунта.
  6. Если среда остановлена, нажмите «Запустить Engee». В подтверждении проверьте выбранную версию и таймаут простоя, затем разрешите действие.
  7. После запуска интерфейс сам проверяет готовность среды каждые 3 секунды, до 2 минут. Дождитесь готовности: статус запущенной сессии может появиться раньше, чем сервер подготовится к вычислениям. Если ожидание закончилось или было отменено, позже нажмите «Проверить Engee». Выполнение кода также ожидает готовности сервера.
  8. Чтобы изменить версию уже работающей среды, сначала нажмите «Остановить Engee» и подтвердите остановку. Приложение не перезапускает работающую среду автоматически.
  9. В «Диалоге» откройте значок папки рядом со скрепкой или отправьте /files. Выберите сохранённый .jl или .ngscript и нажмите «Выполнить в Engee». Проверьте код в подтверждении и реальный результат запуска.

Где остаются данные входа

PAT, логин и пароль Engee хранятся в локальных настройках и используются для подключения к Engee. Они не включаются в контекст модели. Сохранённые секреты обратно не раскрываются: интерфейс показывает их маску и наличие. «Показать/Скрыть» относится только к новому введённому значению. Для удаления сохранённого логина и пароля отметьте соответствующий пункт и сохраните настройки.

В примерах проекта используйте встроенные графические функции Engee без подключения дополнительной графической библиотеки. Проверяйте фактический результат запуска, особенно если код подготовила маленькая локальная модель.

Остановка приложения и среды

«Остановить приложение» завершает локальный Engee Agent. Остановка среды Engee - отдельное действие внутри её подключения, которое требует вашего подтверждения. Отмена ожидания готовности прекращает ожидание в Agent и сама по себе не останавливает Engee; для остановки среды используйте «Остановить Engee».

Сохранённые данные

Сохранённый логин Engee показывается в настройках. Сохранённые пароль, токен Engee и API-ключ провайдера отмечены фиксированной маской из восьми точек и «Сохранён»; их значения не возвращаются в интерфейс. Для замены введите новое значение. «Показать/Скрыть» показывает только новое введённое значение в текущем поле. Не копируйте секреты в диалог, вложения или навыки.

Личный архив

Личный ZIP может включать ваши сохранённые данные Engee и ключи провайдеров. Храните его для собственного переноса. Общая инструкция и иллюстрации не содержат ваших данных входа.

Шаг 13

Выбрать среду и выполнить код из диалога

Нейросеть предлагает код, а выбранная среда выполняет его после вашего подтверждения. Можно выполнить своё выражение напрямую, не отправляя его LLM.

  1. Нажмите ⚙ рядом со значком i у кнопки «Отправить». В меню «Код в чате» выберите Engee или «Локальная Julia». По умолчанию выбрана Engee. Для Julia сначала установите её и проверьте путь в «Параметры → Компоненты». Недоступный вариант отключён; меню показывает причину либо найденную версию.
  2. Введите /eval 1+1 либо /eval sin.(1:2) и отправьте команду. Можно открыть i → «Команды» и выбрать /eval: он только вставится в поле, после чего допишите код и нажмите «Отправить». При ручном вводе / остаются подсказки команд. /eval направляет код в выбранную среду без обращения к нейросети; вложения к вычислению не добавляются.
  3. Если ответ модели содержит блок с языком julia или jl, нажмите рядом с ним «Выполнить». Действие доступно и для Claude Code или сервиса без инструментов. Кнопка относится к этому блоку кода; Python, JSON и нативный .ngscript через неё не выполняются.
  4. В подтверждении проверьте полный код, среду выполнения и показанные сведения о папке, версии и программе. «Разрешить» запускает именно подтверждённый код; при отказе он не выполняется. Выбор нейросети и переключение ⚙ не являются разрешением на запуск.
  5. Дождитесь результата с источником «Engee» или «Локальная Julia» и фактическим выводом либо ошибкой. Для нового запуска снова требуется подтверждение. Сохранить код можно отдельной кнопкой «Сохранить в проект».
  6. Для итоговой проверки проекта выберите Engee. Откройте файлы проекта значком папки в диалоге или командой /files. «Выполнить в Engee» всегда запускает сохранённый .jl/.ngscript в Engee, независимо от ⚙ в чате.
/eval 1+1

/eval sin.(1:2)

После ручного выполнения через /eval или «Выполнить» точный код и фактический результат добавляются в историю диалога и войдут в следующий контекст нейросети. Сам запуск не отправляет отдельный запрос LLM; результат можно проверить заранее через i → «Контекст».

Локальная Julia выполняет код на этом ПК

Подтверждённый Julia-код запускается отдельным процессом в выбранной папке Engee с обычными правами вашего пользователя. Это не изолированная файловая песочница: код может читать и изменять доступные файлы. Проверяйте весь код до разрешения. Вычисление ограничено 30 секундами; вывод stdout и stderr — суммарно 256 КиБ, код — 64 КиБ. Кнопка «Остановить» прекращает собственный процесс вычисления, не закрывая ручной терминал.

Выбранная среда относится к текущему диалогу и запоминается вместе с ним. /clear очищает активный диалог и его сессию Claude, сохраняя выбранную среду. /new создаёт другой диалог; прежние сохраняются в локальной истории. Во время запроса переключение отключено. Модель не переключает среду самостоятельно; при Julia её инструмент вычисления относится к Julia, при Engee — к Engee. Операции с файлами проекта и подключением Engee остаются отдельными действиями.

Если предложенное выполнение Julia отклонено, текущий запрос останавливается: остальные предложенные действия не выполняются и повторные подтверждения автоматически не появляются. Смена среды сама по себе не очищает диалог; ранее полученные результаты сохраняются как текст. Чтобы начать без прежнего контекста, используйте /clear или /new.

Локальная Julia получает чистый Julia-текст. Пакеты автоматически не устанавливаются; для каждой проверки используется отдельное окружение зависимостей приложения и стандартная библиотека, без пользовательского startup.jl и истории REPL. Успешная локальная проверка формулы не подтверждает работу API Engee, нативного .ngscript или модели .engee: итоговую проверку выполняйте в Engee.

  • Настроить и запустить Engee
  • Сохранить и выполнить файл проекта

Шаг 14

Сообщения, вложения и команды

Добавляйте только данные, необходимые для текущей задачи. Содержимое выбранных файлов и вложений входит в контекст модели после отправки.

Проверить вычисление

Введите /eval 1+1 или откройте i → «Команды» и выберите /eval. Выбор только вставляет команду: допишите код и отправьте её. Код выполнится в среде, выбранной через ⚙ «Код в чате», после проверки точного кода и разрешения. По умолчанию это Engee. Для результата смотрите источник выполнения, а не только ответ нейросети.

  1. В поле сообщения опишите цель, исходные данные и ожидаемый результат.
  2. Нажмите значок скрепки у поля сообщения, чтобы добавить текст, код или изображение. Содержимое файла проекта можно добавить из соседнего значка папки кнопкой «Добавить в диалог».
  3. Проверьте список вложений. Удалите лишние элементы до отправки.
  4. Нажмите «Отправить» или Enter: запрос сразу идёт выбранной модели. Shift + Enter вставляет новую строку. Кнопка «Остановить» прерывает текущий запрос, но уже подтверждённые и выполненные действия остаются выполненными.
  5. Для списка команд откройте i → «Команды». Выбор заменяет текст поля выбранной командой, закрывает окно и возвращает курсор в поле; он не запускает команду. Проверьте и дополните текст, затем нажмите «Отправить» или Enter. При ручном вводе / доступно автодополнение. Обычная задача отправляется выбранной модели.

Окно i «Контекст и команды»

При открытии i выбрана вкладка «Контекст»: она показывает получателя, модель и подготовленные данные запроса — черновик, вложения, системные инструкции, историю и результаты инструментов. Просмотр и переключение вкладок ничего не отправляют и не меняют текст. Во вкладке «Команды» выбор заменяет текст поля выбранной командой и закрывает окно; запуск произойдёт только после отправки. «Закрыть» возвращает к диалогу без отправки.

Текст и код до 1 МБ на файл: .txt, .md, .jl, .ngscript, .json, .csv, .yaml, .yml, .v, .sv, .py, .mjs, .js, .html, .css, .log. Изображения до 4 МБ на файл: .png, .jpg, .jpeg, .webp. GIF, PDF, DOCX, .engee, аудио и ZIP как вложения не поддерживаются. Для картинки нужна модель с поддержкой изображений.

Размер вложений

До 5 вложений за сообщение. Текстовые файлы ограничены 1 МБ, изображения - 4 МБ на файл. Крупные данные сокращайте до нужного фрагмента: размер файла, ограничение контекста модели и квота провайдера действуют одновременно.

Локальная история: до пяти диалогов

  1. Нажмите компактный значок «История диалогов» внизу рядом с i у поля сообщения, чтобы открыть список сохранённых диалогов и перейти к нужному. История хранится локально на этом ПК.
  2. Введите /new и отправьте команду, чтобы создать отдельный диалог. Предыдущий диалог сохраняется; у каждого свои сообщения, черновик поля, вложения и выбранная среда выполнения кода.
  3. Если уже сохранены пять диалогов, откроется «Создать новый диалог?» с именем самого давно открывавшегося неактивного диалога. «Создать диалог» удалит именно его только после успешной записи нового; «Отмена» сохранит все пять. Удаление требует вашего выбора.
  4. /clear очищает только активный диалог и сбрасывает его контекст Claude. Другие сохранённые диалоги остаются доступными.

После следующего запуска приложение восстанавливает локальную историю и сохранённые черновики. При выходе через ⏻ запись истории входит в этап «Сохранение…». Для нового выполнения кода снова отправьте команду и подтвердите действие.

Перед подтверждением кода

Смотрите точный текст, среду, рабочую папку и сведения о программе. Подтверждение одного действия не разрешает другой код. «Остановить» прерывает текущий запрос или вычисление; уже завершённые записи и изменения не отменяются автоматически.

Не вставляйте API-ключи, PAT, пароли и сеансы в диалог, вложения, навыки или файлы проекта. Нужный ключ вводится в поле своего подключения. При диагностике сообщайте HTTP-код и текст ошибки без секретов. Для переноса рабочих файлов используйте выбранную папку проекта; они не добавляются автоматически в архив приложения.

Для сохранения перед выходом используйте ⏻ и дождитесь завершения «Сохранение…». Готовые параметры подключения сохраняются в локальных настройках; незавершённые формы восстанавливаются как черновики. Для сборки без интерфейса оставлены Build-Public-ZIP.cmd и Build-Personal-ZIP.cmd: сначала завершите приложение, затем запустите нужный файл. Сохранённые лицензии сторонних компонентов должны оставаться в пакете. Для наборов моделей более 4 ГБ используйте внешний архиватор с ZIP64.

В ZIP не входят установленные вне приложения программы, модели Ollama/LM Studio, рабочие файлы выбранного проекта, история диалогов, вложения, терминальные процессы и сессии CLI. История и вложения остаются в используемой папке приложения, рабочие файлы — в подключённой рабочей папке; сборка ZIP их не удаляет.

Что означает проверка переноса

Запуск распакованной копии в отдельном профиле на текущем Windows проверяет самостоятельность комплекта, в том числе работу без внешних Node.js и Python в PATH. Это отличается от проверки на чистой Windows в отдельной виртуальной машине. Такая проверка чистой ОС не заявляется.

Шаг 20

Работать во встроенном терминале

Вкладка «Терминал» открывает настоящую оболочку на этом компьютере в выбранной папке проекта Engee.

  1. В «Параметры → Файлы проекта → Рабочая папка» выберите рабочую папку Engee. В «Компоненты → Пути программ» можно проверить или вручную указать путь к PowerShell/Git Bash.
  2. Откройте «Терминал». В списке «Оболочка» выберите PowerShell или доступный Git Bash, затем нажмите «Открыть терминал». Проверьте подпись «Папка сессии»: это начальная папка созданной оболочки.
  3. Щёлкните в терминале, введите команду и нажмите Enter. Для простой проверки выполните echo "Engee terminal ready". Вывод появляется в этом же окне, а размер терминала подстраивается под окно автоматически.
  4. Для интерактивной работы с установленным Claude Code вручную введите claude. При первом запуске выполните вход своим аккаунтом по подсказкам CLI; приложение само claude не запускает.
  5. После работы завершите программу и введите exit либо нажмите «Закрыть сессию». После exit интерфейс показывает код завершения; снова открыть оболочку можно кнопкой «Новая сессия».

В терминале работают стрелки, Tab и Ctrl+C. При блокировке opencode.ps1 политикой PowerShell для установки OpenCode через npm попробуйте opencode.cmd. Для установленного исполняемого файла Claude Code используйте claude.

Команды выполняются на этом ПК

Введённые команды выполняются на этом компьютере с обычными правами пользователя и могут изменять его файлы. Диалоговая модель сама этим терминалом не управляет. Вручную запущенный CLI работает по своим правилам; его действия отличаются от подтверждаемых действий помощника в «Диалоге».

Рабочая папка фиксируется при создании сессии. После выбора другого проекта кнопка «Новая сессия» закрывает текущую оболочку этой вкладки и открывает новую в актуальной папке; параллельную сессию она не создаёт. Сначала завершите работу нужной программы. Доступные оболочки обновляет общая кнопка ↻ «Обновить все подключения» в шапке приложения. При закрытии вкладки браузер пытается завершить сессию, но запрос может не успеть. Надёжный способ - «Закрыть сессию». ⏻ сначала сохраняет данные приложения и только после успеха завершает сервер Engee Agent и созданные им терминальные сессии. Процессы оболочек и запущенные в них программы после перезапуска не возобновляются; открывайте новую терминальную сессию.

«Копировать выделенное» копирует выбранный фрагмент терминала. «Очистить экран» убирает отображаемый вывод и сохраняет работающую сессию. Ввод и вывод терминала не добавляются в диалог нейросети.

Windows PowerShell доступен в Windows. Для Git Bash установите Git for Windows на этом ПК; он не входит в ZIP Engee Agent. После установки перезапустите Engee Agent и снова проверьте доступные оболочки.

Julia: локальная проверка вычислений (необязательно)

Julia можно установить отдельно для быстрой проверки чистого Julia-кода: формул, массивов, функций и ошибок выполнения. Ею пользуются через ручной REPL в «Терминале» либо подтверждённый запуск кода в «Диалоге». Для обычного запуска Engee Agent установка Julia не обязательна.

  1. Откройте «Параметры → Компоненты → Julia (необязательно)». Кнопка «Скачать Julia для Windows» загружает официальный установщик Windows x64. На 8 октября 2026 стабильная версия — Julia 1.13.1.
  2. Установите Julia вручную. Если хотите запускать её командой julia, добавьте папку bin установленной Julia в PATH; после изменения PATH перезапустите Engee Agent. Можно обойтись без изменения PATH: укажите полный путь к настоящему julia.exe в поле «Путь к julia.exe», нажмите «Сохранить путь», затем «Найти Julia». Пустой путь включает автоматический поиск. Указывайте исполняемый файл установленной Julia, а не псевдоним WindowsApps или juliaup.
  3. Выберите рабочую папку в «Параметры → Файлы проекта → Рабочая папка». Во вкладке «Терминал» выберите «Julia — локальный REPL» и нажмите «Открыть терминал». Julia запускается только после вашего действия, в выбранной папке проекта.
  4. Введите выражение и нажмите Enter. Для проверки попробуйте 1+1 и sin.(1:2). Первое вернёт 2; второе — два значения примерно 0.84147 и 0.90930. Аргументы sin заданы в радианах. Завершите Julia командой exit() или кнопкой «Закрыть сессию».
  5. После локальной проверки выполните итоговый код в Engee: через /eval в «Диалоге» либо «Выполнить в Engee» для сохранённого файла. Проверьте точный код в окне подтверждения и нажмите «Разрешить».

Обычная Julia проверяет синтаксис и выполнение чистого Julia-кода с доступными ей зависимостями. Установка Julia сама по себе не воспроизводит среду Engee: версии языка, пакеты и настройки проекта могут отличаться. Установить и запустить OpenCode

Кнопка «Скачать OpenCode (CLI ZIP) ↗» загружает официальный архив для Windows x64. Его нужно распаковать; запуск и добавление в PATH не происходят автоматически. Desktop — отдельное графическое приложение.

  1. В «Параметры → Компоненты» нажмите «Скачать OpenCode (CLI ZIP) ↗». Распакуйте весь архив в обычную папку, например C:\Tools\OpenCode. Найдите в ней opencode.exe.
  2. Откройте «Параметры → Нейросети и подключения → Ваши подключения → + Добавить подключение», выберите «Программа» и укажите полный путь к распакованному opencode.exe. Сохраните подключение.

  4. В самом OpenCode выполните /connect и настройте нужного провайдера своим доступом. Настройка OpenRouter в Engee Agent автоматически не настраивает отдельный OpenCode.
  5. Для доступности короткой команды opencode и обнаружения CLI проверкой компонентов можно отдельно добавить папку программы в PATH. Это необязательно для запуска по полному пути. После изменения PATH перезапустите Engee Agent и откройте новую терминальную сессию.
  6. Команды OpenCode работают в выбранной папке с обычными правами вашего пользователя. Для завершения терминальной сессии нажмите «Закрыть сессию». Установка инструмента не означает бесплатный доступ ко всем его моделям.
